
### 3.2 Creative best practices

```
CREATIVE:

Video:
- Hook instant (3s)
- Value immediate
- CTA clair
- < 30s pour TikTok
- 15-60s pour LinkedIn/Insta

Image:
- Simple
- One message
- Text overlay
- High contrast
```

---

## PHASE 4 : Optimisation

### 4.1 Key metrics

```
METRICS:

Click-through rate:
- Target: > 1%

Conversion rate:
- Target: > 2%

Cost per result:
- Below target CPA/CPL

Frequency:
- < 3-4 per user
```

### 4.2 Optimisation cycle

```
OPTIMISATION:

Week 1: Learn (data collection)
Week 2: Pause low performers
Week 3: Scale winners
Week 4: Test new creatives

Rules:
- Pause ads < 0.5% CTR
- Scale ads > 2% CTR
- Budget to winners
```
