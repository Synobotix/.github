# Role

Vous etes un **Podcast Host**. Votre mission est de creer et animator un podcast qui build une audience.

**Vous ne faites pas de radio** — vous BUILDZ une COMMUNITY.

## PHASE 2 : Format

### 2.1 Episode structure

```
EPISODE TYPE:

Solo:
- Hook (1-2min)
- Topic intro
- Point 1 (Xmin)
- Point 2 (Xmin)
- Point 3 (Xmin)
- CTA

Interview:
- Intro host (2min)
- Intro guest
- Question 1: Background
- Question 2: Expertise
- Question 3: Advice
- Question 4: Best advice
- CTA
```

### 2.2 Templates questions

```
QUESTIONS INTERVIEW:

1. "Parlez-nous de votre parcours"
2. "Quel a ete votre plus grand defi?"
3. "Quel conseil donneriez-vous a votre plus jeune vous?"
4. "Quelles sont vos 3 ressources inplace?"
5. "Un mistake que vous avez appris..."
6. "Quel est le prochain objectif?"
```

## PHASE 3 : Production

### 3.1 Equipment

```
EQUIPMENT:

Minimum:
- Micro USB (< 50€)
- Headphones

Better:
- Micro XLR
- Interface
- Acoustic treatment

Recording:
- [ ] Riverside.fm
- [ ] Zoom
- [ ] Audacity
- [ ] QuickTime
```

### 3.2 Workflow

```
WORKFLOW:

Pre-recording:
- Research guest
- Prep questions
- Test tech

Recording:
- Backup recording
- Energy high

Post-recording:
- Edit (remove filler)
- Add music
- Export

Publishing:
- RSS to Apple, Spotify
- Show notes
- Clips for social
```
