# WORKING METHOD

## PHASE 1 : Preparation

### 1.1 Questions

```
QUESTIONS :

1. Type de demo:
   - [ ] Produit
   - [ ] Service
   - [ ] SaaS
   - [ ] Consulting

2. Duree cible:
   - [ ] 15min
   - [ ] 30min
   - [ ] 60min

3. Audience:
   - [ ] Solo
   - [ ] Team
   - [ ] Committee
```

### 1.2 Structure demo

```
STRUCTURE:

Opening (3min):
- Introduction
- Agenda
- Confirm pain points

Demo principal (15-20min):
- Key feature 1
- Key feature 2
- Key feature 3

Value demonstration (5min):
- Use case
- ROI/benefits

Q&A (10min):
- Handle objections

Close (2min):
- Next steps
- CTA
```

---

## PHASE 2 : Delivery

### 2.1 Opening

```
OPENING:

"Hi everyone, thanks for your time today.
Avant de commencer, je want to confirm:
- [Pain point 1]
- [Pain point 2]

Today's goal: [Show how we solve X]

Let's go."
```

### 2.2 During demo

```
TIPS:

- Smile, be energetic
- Mouse: Follow along
- Talk: Explain as you go
- Pacing: Not too fast/slow
- Key moments: Pause for effect
- Objections: Note for later

What NOT to do:
- Don't read notes
- Don't go silent
- Don't rush
- Don't over-feature
```

---

## PHASE 3 : Q&A et objections

### 3.1 Common objections

```
OBJECTIONS + RÉPONSES:

"Trop cher"
→ "Je comprends. Qu'est-ce qui est le plus important?"
→ "Le cout de ne pas agir..."

"Pas le temps"
→ "On average, cela prend X temps"
→ Quick version available

"Je dois reflechir"
→ "Quelles sont vos questions?"
→ "Deadline?"

"Passe par committee"
→ "Qui decide?"
→ "Je peux presenter a..."
```

### 3.2 Handling

```
HANDLING:

1. Listen fully
2. Empathize
3. Ask clarifying
4. Address with proof
5. Confirm resolved

Tips:
- Don't interrupt
- Repeat the objection
- Use case studies
- Ask "Does that help?"
```
