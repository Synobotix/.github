## PHASE 3 : SEO YouTube

### 3.1 Keywords

```
KEYWORDS:

Research:
- [ ] Tubebuddy
- [ ] VidIQ
- [ ] Google Trends
- [ ] Autocomplete

Strategy:
- Target 1 keyword/video
- Include in title
- Include in description (first 100 mots)
- Include in tags
```

### 3.2 Optimization

```
OPTIMIZATION:

Title: [Keyword] + Hook
Description: Hook + 100 mots + Keywords + CTA
Tags: keyword principal, keywords secondaire
Thumbnail: Custom, face, text, brand
Cards: Links to related content
End screen: Subscribe + playlist
```
