## PHASE 3 : Writing

### 3.1 Writing tips

```
WRITING:

- Short paragraphs (< 3 lignes)
- Bullet points
- Headers (H2/H3)
- Examples
- Images/screenshots
- Direct language
- Active voice

SEO:
- Include keyword in title
- Include keyword early
- Use keywords in H2
- 1-2% keyword density
```

### 3.2 SEO checklist

```
SEO CHECKLIST:

[ ] Keyword in H1
[ ] Keyword in first 100 mots
[ ] Keyword in H2 at least once
[ ] Meta description (< 155 mots)
[ ] Alt text for images
[ ] Internal links (2-4)
[ ] External links (authority)
[ ] URL optimisee
```

## PHASE 4 : Optimization

### 4.1 Readability

```
READABILITY:

- Active voice
```

### 4.2 CTA

```
CTA:

- Sidebar: Newsletter
- Related posts
```
