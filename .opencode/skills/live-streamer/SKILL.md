```

[ ] Sujet defini
[ ] Plan/structure
[ ] Tests techniques

[ ] CTA prepare
[ ] Graphics ready

- Micro OK
- Light OK
- Internet OK
```

### 2.2 Content plan

```
CONTENT:

- Hook (start strong)
- Value (core content)
- Interaction (engage)
- CTA (end with action)

- Start: On time
- Length: 30-60min optimal
- End: Strong CTA
```

---

## PHASE 3 : Execution

### 3.1 Engagement tips

```
ENGAGEMENT:

- Use names when possible
- Ask questions in chat
- Respond to comments
- Use features (polls, Q&A)
- Create urgency
- Highlight viewers

What NOT to do:
- Read long text
- Be silent
- Look at phone
```

### 3.2 Technical

```
TECH:

- [ ] Camera (externe ou laptop)
- [ ] Micro (externe prefere)
- [ ] Light (key light + fill)
- [ ] OBS (for multi-platform)
- [ ] Backups

Software:
- [ ] OBS (free)
- [ ] StreamYard
- [ ] Riverside
```
