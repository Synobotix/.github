# SKILLS GROUPÉS

## Phase 1 : STRATÉGIE ET OFFRE
```
business-strategy
```
→ Definir l'offre, la cible, le pricing, l'avantage concurrentiel

## Phase 2 : CONCEPTION
```
funnel-architect
```
→ Concevoir le funnel, le parcours prospect → client, tracking

## Phase 3 : CRÉATION CONTENU
```
content-strategist
```
→ Strategie blog, sujets editoriaux, calendrier

```
seo-specialist
```
→ SEO, mots-cles, optimisation

```
copywriter
```
→ Textes de conversion, CTAs, landing pages

## Phase 4 : IMPLÉMENTATION
```
funnel-builder
```
→ Implementer CTAs, formulaires, pages, tracking

```
email-marketer
```
→ Sequences email, automation, newsletter

## Phase 5 : ACQUISITION
```
linkedin-strategist
```
→ LinkedIn global

```
linkedin-poster
```
→ Posts performants

```
linkedin-outreach
```
→ Prospection B2B

```
linkedin-engagement
```
→ Commenter et reseau

## Phase 6 : ANALYSE ET OPTIMISATION
```
funnel-audit
```
→ Analyser, score, recommandations
