## PHASE 3 : Video testimonials

### 3.1 Setup

```
VIDEO:

Duration: 30s - 2min
Format: Talking head
Q1: "Parlez-nous de votre experience..."
Q2: "Quel resultat avez-vous obtenu?"
Q3: "A qui recommanderiez-vous cela?"

Setup:
- Phone/Laptop
- Landscape
- Good lighting
- Clean background
- Test before
```

### 3.2 Structure

```
STRUCTURE:

Intro:
"Hi, I'm [Name] from [Company]..."

Body:
"I was struggling with [problem]..."

Value:
"[Company] helped me by [solution]..."

Result:
"In just [time], we saw [result]..."

Close:
"I would recommend [Company] because..."
```
