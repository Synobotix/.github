## PHASE 4 : Creation workflow

### 4.1 Production

```
WORKFLOW:

1. Idea (5min)
2. Script hook (30s)
3. Shoot (5-10 take)
4. Edit (CapCut 10min)
5. Post

Batch:
- Batch ideas
- Batch shoot
- Batch edit
- Schedule

Tools:
- [ ] CapCut (free)
- [ ] InShot
- [ ] Premiere Rush
```

### 4.2 Editing tips

```
EDITING:

- Hook in first 3s
- Cut dead space
- Use trending sounds
- Text overlays
- Transitions
- Fast pacing
- End with CTA
```
